# Kuripara High School Server
kuripara high school server make connection between school website and database all data stay secure in database

## Technology Use
| Technology | Uses |
|------------|------|
| Node | Js Runtime |
| Express | Api |
| Rest Api | Json data |
| MongoDB | Database |
| Redis | Cashing |
